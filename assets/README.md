# Assets 디렉토리

이 디렉토리에는 트레이 아이콘 이미지 파일이 포함됩니다.

## 필요한 파일

- `icon.ico`: Windows용 아이콘 파일
- `icon.png`: macOS/Linux용 아이콘 파일
- `icon_running.png`: 실행 중 상태 아이콘 (선택)
- `icon_stopped.png`: 중지 상태 아이콘 (선택)
- `icon_error.png`: 오류 상태 아이콘 (선택)

## 아이콘 생성 방법

1. 온라인 아이콘 생성기 사용 (예: https://www.favicon-generator.org/)
2. 이미지 편집 소프트웨어 사용 (예: GIMP, Photoshop)
3. 아이콘 라이브러리에서 다운로드

## 권장 사양

- **icon.ico**: 64x64 또는 128x128 픽셀
- **icon.png**: 64x64 또는 128x128 픽셀
- 형식: PNG (투명 배경 권장)
